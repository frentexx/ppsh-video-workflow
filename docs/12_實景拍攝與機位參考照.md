# 12 實景拍攝與機位參考照

> 📌 整理自屏北高中「影音生成」專案的《校園實景拍攝清單》（2026-10-22 建立、10-23 補機位參考照）與《團結》背景重繪實驗。
> 用途：拿真實校園照片取代 AI 生的「場景母版」，讓背景（桌椅樣式、排法、窗戶、走廊、操場）就是自己的學校。**人物還是 AI 生的**，照片只當背景參考圖。

## 為什麼一定要拍實景（2026-10-23 的教訓）

- 《團結》v6 的首幀用 AI 想像的場景母版：教室變成木頭桌椅＋正午強光（實景是藍綠塑膠椅、灰桌、日光燈、綠窗簾），走廊變成二樓陽台有欄杆（實景是一樓、柱子＋草地），教室畫面裡還看得到走廊。
- **H3 的背景完全由首幀決定**：改寫 H3 的場景描述，畫面幾乎一模一樣（`10_影片品質實驗.md` 第 2 階段）。
- 事後補救要靠 `tools/bg_inpaint.py` 逐鏡重畫背景（每張約 75 秒，再整片重跑 H3）。
- ⇒ **新片一開始就用實景照當場景母版**：film.json `masters` 寫 `{"photo": "..."}`，make_film.py 會直接裁成母版，不再生 AI 場景。

## 學校沒有的場景怎麼辦

每一鏡只會用到母版的**一小塊**（裁切），劇中「兩個地方在旁邊」是靠**剪接**交代，不需要真的拍在同一個畫面裡。

| 情況 | 怎麼處理 |
|---|---|
| 劇本要的房間學校沒有（例：器材室） | 找**任何一間類似的小房間**代替；真的都沒有，那幾鏡繼續用 AI 母版——另一個地點，與實景鏡頭交錯剪接不會穿幫 |
| 劇本要的擺設現場做不到（例：椅子全倒放） | 照平常擺設拍，差異交給提示詞；先試 2～3 鏡，加不上去就改劇本細節 |
| 劇本要的建物沒有（例：司令台） | 改用現有的相近場景（例：草場旁階梯） |

## 共通拍攝規則（每張都要遵守）

| 項目 | 規則 | 原因 |
|---|---|---|
| **不能有人** | 假日或放學後拍；尤其不能拍到學生的臉 | 個資；而且模型會把照片裡的人一起畫進首幀 |
| **不能有看得清楚的字** | 班牌、海報、布告欄、標語、黑板字、校名牌，能拿掉就拿掉、黑板擦乾淨；拿不掉就換角度避開 | AI 會把字畫成亂碼；《團結》背景重繪把班級牌「302」畫了出來。校名一律後製疊字 |
| 鏡頭 | 手機**主鏡頭 1x**，不要 0.5x 超廣角 | 超廣角邊緣會變形，合成人物時比例會怪 |
| 方向 | **橫拿**；16:9 或 4:3 都可（會裁成 1.75:1） | 成片是寬銀幕 |
| 高度 | 站姿眼睛高度約 150～160 cm；坐姿約 110 cm | 對白鏡大多是平視 |
| 水平 | 手機拿正，不仰不俯（開格線輔助） | 歪的背景合成後人會像站在斜坡上 |
| 畫質 | 最高解析度、關美顏／濾鏡／人像模式；HDR 可以開 | |
| 張數 | 每個角度拍 2～3 張，每張左右移一小步 | 方便挑、也方便裁不同景別 |
| 光線 | 在片中時段拍；照片的光線方向會被模型照著畫 | 《團結》建議陰天柔光，不要正午硬光 |
| 檔名 | `代號_序號.jpg`，例如 `A1_1.jpg`；同角度早上／黃昏加 `m`／`d`，例如 `A1m_1.jpg` | 對照機位表就知道是哪個角度 |
| 存放 | 影片資料夾的 `input_scene\` | **不進 git、不送雲端** |

## 依分鏡拍「機位參考照」（2026-10-23 補充，最重要）

**為什麼**：背景重繪時，AI 會照參考照的透視（桌椅走向、消失點、鏡頭高度）畫背景。《團結》只用一張「教室內由後往前、站著斜拍」的照片，結果坐著的學生近景背景也變成俯視的斜 45 度桌椅，人物像貼上去的。

**做法**：分鏡表定稿後，每個機位拍一張（同一機位的多鏡可共用），檔名寫機位代號，並在機位表（`templates/新片/機位表.md`）註明下列五項：

| 項目 | 寫法例 | 說明 |
|---|---|---|
| 位置與方向 | 「教室後門 → 講台」「講台 → 後牆布告欄」「走廊東端 → 西」 | 決定背景出現黑板或布告欄、柱子在左或右 |
| 鏡頭高度 | 坐姿眼高約 110 cm／站姿眼高約 160 cm | 坐著的人物近景一定用坐姿高度拍 |
| 角度 | 正對 90 度／斜 45 度 | 跟人物在分鏡裡面向的方向一致 |
| 景別 | 遠景（整間）／中景（兩三排）／近景背景（一面牆） | 近景人物只需要一小塊背景，不要用全景照 |
| 光線時段 | 中午、陰天、開燈或不開燈 | 跟片中時段一致 |

## 場景描述也要照實景寫（並固定方向）

《團結》學到：走廊、教室牆這類會反覆出現的場景，要把**方向與材質**寫死，放在 film.json 的 `snippets`，每鏡用 `{名稱}` 引用，避免各鏡寫法不一致。例（屏北一樓走廊）：

```
左＝方柱＋草地（無牆、無欄杆）；右＝教室牆：紅磚只到窗台、白色水泥窗台、深色窗框、窗間深灰抿石子牆柱、窗上米白牆（窗戶上方沒有紅磚）；陰天柔光
```

- qwen-edit 改構圖時，中間常生出一塊空白水泥牆 → 提示詞寫「牆面橫跨整個畫面連續、不能有空白牆段」。
- 教室鏡一律寫「封閉教室、看不到走廊」；走廊鏡寫「一樓、柱子＋草地、無欄杆」（依自己學校改）。

## 道具（選拍）

Qwen-Image-Edit 最多可以附 3 張參考圖，有實物照片能讓道具每鏡都長一樣。放在素色桌面或牆前，正面、斜 45 度各一張。
但**避免讓角色手拿會掉落的道具**（作業簿、保溫瓶）：掉落前後不一致、快速動作中會糊成色塊（《團結》N1、X1）。

## 附錄：屏北高中場景代號範例（SEL 第 1 集用）

| 代號 | 場景 | 主要角度 |
|---|---|---|
| A1～A7 | 普通教室（早上／黃昏同角度） | A1 講台旁前角落往後拍 ⭐；A2 後牆中間往黑板 ⭐；A3、A4 坐姿；A5 講台往座位；A6 窗邊往前門 ⭐；A7 桌椅、講桌、黑板細節 |
| B1～B3 | 教室外走廊 | B1 前門外往門裡 ⭐；B2 門口往走廊一端（一點透視）⭐；B3 往操場 |
| C1～C4 | 草場旁階梯 | C1 平視正面 ⭐；C2 斜 45 度；C3 坐階梯往草場；C4 材質特寫 |
| D、E | 小房間門口／內部（代替器材室） | 正面門半開 ⭐；室內往門口 ⭐ |
| F1～F3 | 司令台 | 平視正面 ⭐；斜 45 度；坐台階往操場 |
| G1～G6 | 系列預留：校門、樓梯間、福利社、球場、圖書館、專科教室 | — |

拍完之後的流程：挑每個角度最好的一張 → 寫進 film.json `masters`（`{"photo": ...}`）→ **先試 2～3 鏡首幀**＋`bgcheck.py ref` 量分數 → 確定比 AI 母版寫實再整批跑。
